# Keywise frontend

Frontend React приложение поиска цен. Ходит в собственный API keywise_backend: `GET /search?q=''&region=''`.

## Setup

Скопируй `.env.example` в `.env` и заполни значения

```bash
yarn install
```

## Get started

```bash
yarn dev
```

Приложение откроется на <http://localhost:8080>.

```bash
yarn build
yarn preview
```
